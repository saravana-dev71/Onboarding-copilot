## 9. Errors and Verified Fixes

### Error 1 — `fastapi-mcp`/`mcp` version incompatibility (CRITICAL)

**Affects:** `test_rest.py` (35 tests), and the Python backend server startup.

**Symptom:**
```
server.py:336: in <module>
    mcp = FastApiMCP(app)
fastapi_mcp/server.py:144: in setup_server
    mcp_server: Server = Server(self.name, self.description)
TypeError: Server.__init__() takes 2 positional arguments but 3 were given
```

**Root cause:** `requirements.txt` does not pin versions for `fastapi-mcp` or `mcp`. The latest resolver installed `fastapi-mcp==0.4.0` and `mcp==2.2.0`. The `mcp 2.2.0` library changed the `Server` constructor from `Server(name, description)` to `Server(name)` (description removed), breaking `fastapi-mcp 0.4.0`.

**Installed versions:**
- `fastapi-mcp`: 0.4.0
- `mcp`: 2.2.0
- `fastmcp`: 4.0.10

**Recommended fix (not applied — no version pins documented in the repository):**

Add explicit version pins to `requirements.txt`. The correct approach is to determine which `mcp` version `fastapi-mcp 0.4.0` was tested against and pin it, for example:

```
fastapi-mcp==0.4.0
mcp==1.9.4
```

Or upgrade `fastapi-mcp` to a version that supports `mcp 2.x`. This fix requires a repository maintainer to test and commit the pin — it is **not invented here**.

### Error 3 — Java 25.0.1 installed (incompatible)

**Affects:** Java hold service build, tests, and startup. Also affects e2e tests.

**Symptom:** `java -version` returns `25.0.1`. Lombok annotation processing is incompatible with Java 22+.

**Root cause:** The system Java installation is Java 25, but the project requires Java 17 or 21.

**Resolution:** Install Java 17 or 21 (e.g. Adoptium Temurin) and set `JAVA_HOME`:
```powershell
$env:JAVA_HOME = "C:\path\to\jdk-17"
$env:PATH = "$env:JAVA_HOME\bin;$env:PATH"
java -version  # should show 17.x
```
